# Логіка системи безпеки — документація для людей

Цей документ пояснює, як система безпеки ухвалює рішення: що вона вже вміє, як саме працює, чому так і звідки
взялися всі формули та числа. Він написаний для читача без досвіду програмування: керівника, рецензентів кафедри,
усіх, хто хоче зрозуміти логіку.

Документ складається з трьох частин:

1. [Частина 1. Автономна локальна система (стаття 1)](part1_autonomous.md) — нечітка система, яка працює без
   інтернету: газ, камера, мікрофон і верхній рівень.
2. [Частина 2. Мультиагентний підхід (стаття 2)](part2_multiagent.md) — агенти, які додають розпізнавання дій і
   змісту мови, та правила, за якими вони не можуть зробити систему менш безпечною.
3. [Джерела, покажчик формул і словник](references.md).

Усі рисунки, таблиці та числа в тексті створює програма з поточних налаштувань системи. Тому документ не може
розходитися з тим, як система працює насправді: після кожної зміни налаштувань його перебудовують однією командою.
Якщо для якогось значення джерела немає, документ так і каже. Те, що ще не зроблено, позначено словом
«заплановано».

## Як читати

- Кожен механізм спочатку показано на рисунку, потім коротко пояснено, далі наведено приклад зі справжніми числами.
- Квадратні дужки з числом, наприклад [1], — посилання на джерело в списку джерел.
- Позначення «Ф1», «Ф2» … — номери формул; усі формули зібрано в покажчику формул.
- Кожен термін пояснено там, де він трапляється вперше; короткий словник — наприкінці.
